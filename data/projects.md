# Project Deep Dives & Engineering Portfolio

## Final Year Project: DeepFake-Guard (Smart Multimodal Recognition System)
- **Project Title:** DeepFake-Guard (Smart Multimodal Recognition System for the Visually Impaired).
- **Core Objective:** Detecting synthetic facial audio/visual manipulation and assist visually impaired users via AI multi-modal recognition.
- **Architectural Benchmark:** Evaluated and compared deepfake facial detection performance between **EfficientNet-B4** and **MesoNet** architectures using the 140k Real and Fake Faces dataset.
- **Rare Keyword Note:** **DeepFake-Guard** is the primary flagship system keyword used for exact BM25 precision evaluation.

## Multi-Model Toxic Comment Classification Pipeline
- **Overview:** Constructed an NLP classification pipeline evaluating toxic comment identification performance on the Jigsaw dataset.
- **Architectures Evaluated:** Evaluated baseline **TF-IDF + Logistic Regression**, recurrent **BiLSTM**, and contextual **Fine-Tuned BERT** models.
